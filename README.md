# Currency Converter

A simple and user-friendly currency converter web application built with HTML, CSS, and JavaScript.

## Features

- Convert between multiple currencies
- Real-time exchange rates from exchangerate-api.com
- Dark mode toggle
- Reverse currency selection
- Accessible design with ARIA labels
- Loading indicator
- Error handling for invalid inputs and API failures

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- exchangerate-api.com API

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/BinaryVortex/Currency-Converter-2.git
   ```

2. Open `index.html` in your web browser.

## Usage

1. Enter the amount to convert.
2. Select the source currency from the "From" dropdown.
3. Select the target currency from the "To" dropdown.
4. Click the "Convert" button to see the result.
5. Use the "Reverse" button to swap currencies.
6. Toggle dark mode using the moon icon button.

## API Key

This project uses a free API key from exchangerate-api.com. For production use, consider obtaining your own API key.
